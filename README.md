# Bootstrap Collapsible Navbar

A small single-page website with a Bootstrap navbar that collapses on mobile. I made it while learning Bootstrap.

## Features

- Fixed navbar that stays at the top when you scroll
- Navbar collapses into a hamburger menu on small screens
- Menu closes by itself when you click a link on mobile
- Smooth scrolling to page sections (Home, Features, About, Contact)
- Simple contact form (front-end only, it does not send anything)
- Footer shows the current year automatically

## Tech stack

- Bootstrap 5.3.2 (CSS and JS files are included in the repo, so it works offline)
- Plain HTML, CSS and a little JavaScript
- No build step needed

## How to view

1. Download or clone this repo.
2. Open `index.html` in any browser.

That is it. There is nothing to install.
